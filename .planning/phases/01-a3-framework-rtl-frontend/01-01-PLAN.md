Create `src/config.py`:

```python
def load_config(config_path, circuit_id):
    """Load per-circuit point configuration from config.json.
    
    Returns list of point configs. Falls back to $default if circuit_id not found.
    Each element can be any JSON — tool interprets its own fields.
    """
    import json
    with open(config_path) as f:
        config = json.load(f)
    
    circuit_config = config.get(circuit_id, config.get("$default", []))
    return circuit_config
```

<action>
Create `src/synth.py` — the core synthesis script:

1. Parse CLI args: --rtl, --top, --sdc, --liberty, --config, --circuit, --point, --out-dir. If `--top` is not provided, look for `problem.yaml` in the same directory as `--rtl` and parse it (YAML or regex) to extract `top_module` field as default. Similarly, if `--sdc` is not provided, check for `constraints.sdc` in the same directory as `--rtl`. Parse `problem.yaml` for clock name, clock period, and reset signal metadata when present — these inform SDC constraint generation if needed.

2. Load config for the given circuit/point using config.py

3. Generate a Yosys script file (`_synth.ys`) that executes:
   ```yosys
   read_liberty -lib {liberty}
   read_verilog {rtl}
   hierarchy -check -top {top}
   proc
   opt_expr
   opt_clean
   opt_merge
   fsm
   opt
   wreduce
   peepopt
   alumacc
   share
   opt
   memory_map
   opt
   techmap
   opt
   abc -liberty {liberty} -script "{abc_script}"
   dfflibmap -liberty {liberty}
   opt
   clean
   write_verilog {out_dir}/netlist.v
   ```

4. Run Yosys: `yosys -q -s _synth.ys`

5. Verify output: `netlist.v` exists and is non-empty

**CRITICAL (from research pitfalls):**
- abc script MUST include `map` at the end (without it, output is NOT a mapped netlist)
- `dfflibmap` MUST come after `abc` (maps flip-flops to library cells)
- Handle SDC: read constraints with `read_sdc` or pass via abc `-constr` flag
</action>

<acceptance_criteria>

</acceptance_criteria>
