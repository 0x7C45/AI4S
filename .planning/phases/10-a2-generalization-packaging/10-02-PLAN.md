```jinja
{% elif "valid-ready" in design_info.inferred_protocols or "AXIS" in design_info.inferred_protocols %}
    # valid-ready stream golden model（per 门禁 #5：真实比对 DUT 输出）
    # axis_fifo_adapter 在 S_DATA_WIDTH==M_DATA_WIDTH 时是纯延迟（shift register）
    golden_queue = collections.deque()  # 参考模型：记录每拍输入，按握手出队比对

    async def _vr_drive_and_check(index):
        # 驱动 s_axis 输入（valid + data + 随机 ready 反压）
        s_data = index & 0xff
        dut.s_axis_tvalid.value = 1
        dut.s_axis_tdata.value = s_data
        dut.m_axis_tready.value = random_random() < 0.7  # 反压
        await RisingEdge(dut.clk)
        # 若输入握手成功，入参考队列
        if dut.s_axis_tvalid.value and dut.s_axis_tready.value:
            golden_queue.append(s_data)
        # 若输出握手成功，比对
        if dut.m_axis_tvalid.value and dut.m_axis_tready.value:
            got = int(dut.m_axis_tdata.value)
            assert len(golden_queue) > 0, f"output beat {index} but golden queue empty"
            expected = golden_queue.popleft()
            assert got == expected, f"m_axis_tdata mismatch @idx={index}: got=0x{got:x} exp=0x{expected:x}"
```

关键：必须在 `m_axis_tvalid && m_axis_tready` 握手周期采样 `dut.m_axis_tdata.value` 并 assert 等于 golden（shift-register 出队的预期值）。case2 axis_fifo_adapter 在 S=M=8 时是纯延迟，golden = 入队顺序。

需 import collections（模板顶部）。valid-ready 分支替换原 `{% else %}` 占位里的 case2 逻辑；case2 仍走通用输入驱动补足非 stream 端口（如 cfg_*）。

注意端口名自适应：用 design_info.ports 查 m_axis_tvalid/m_axis_tready/m_axis_tdata 是否存在，存在才加该比对（避免 case3/case5 误入此分支）。
