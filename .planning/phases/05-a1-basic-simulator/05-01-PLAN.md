<action>
Implement event-driven simulation engine:

**sim_engine.h/cpp:**
```cpp
class SimEngine {
    // Signal storage: name -> value (support arbitrary width)
    map<string, BitVector> signals;
    
    // Event queue: Active and NBA phases
    queue<Event> activeQueue;
    queue<Event> nbaQueue;
    
    // Module instances
    map<string, ModuleInstance> instances;
    
    // Core methods
    void loadFilelist(string filelist, string topModule);
    void elaborate();  // Resolve hierarchy, initialize
    void run();        // Event-driven simulation loop
    void eval();       // Evaluate one delta cycle
    
    // Expression evaluation
    BitVector evalExpr(ASTNode* node);
    void execStmt(ASTNode* node);
};
```

**Event-driven loop:**
```
while (events pending) {
    // Active phase
    while (!activeQueue.empty()) {
        event = activeQueue.pop()
        evaluate(event)
    }
    // NBA phase
    while (!nbaQueue.empty()) {
        event = nbaQueue.pop()
        apply(event)  // Non-blocking assignments take effect
    }
}
```

**BitVector class** — arbitrary width bit vector:
- Support: arithmetic (+, -, *), bitwise (&, |, ^, ~), comparison (==, !=, <, >), shift (<<, >>), concatenation, bit select, ternary
- Handle: X/Z values (at minimum X for uninitialized)
</action>

<acceptance_criteria>

- Simulator can evaluate always @(*) blocks (combinational sensitivity)
- Bit operations work correctly for 16-bit, 32-bit values
- Concatenation `{}` works
- Ternary `?:` works
</acceptance_criteria>
