## Makefile Interface Design

Spec requires `make run` with NO arguments. `compile_sim` produces self-contained sim.out:

```
compile_sim FILELIST=filelist.txt TOP=tb

     -> Parses RTL, generates sim_data.bin + run_sim.cpp, compiles -> sim.out
run  (no args) -> ./sim.out -> produces tb/output.mem
```
