## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Testbench system calls to host files | `$fopen` and memory loaders can access paths derived from testcase text and runtime CWD. |
| RTL event scheduling to process state | Malformed or cyclic event behavior can exhaust queue or delta iterations. |
| Waveform output to host filesystem | `$dumpfile` selects an output path and receives signal values. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|

| T-06-05 | Tampering | runtime-relative `$readmem*` and `$fopen` paths | medium | mitigate | Normalize paths against the runtime directory, preserve absolute paths, validate handles, and never use unchecked parser buffers. |

</threat_model>
