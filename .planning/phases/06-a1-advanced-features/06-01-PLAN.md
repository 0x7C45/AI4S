<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Filelist/source files to preprocessor | RTL and include contents are untrusted text that can recurse or expand macros. |
| Preprocessor output to flex/bison | Expanded text and source mappings cross into parser memory. |
| Serialized AST/data to runtime | Compile artifacts are read back before simulation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Denial of Service | `preprocessor.cpp` include recursion and macro expansion | high | mitigate | Canonical active-include stack, recursion rejection, bounded expansion, and explicit failure diagnostics. |
| T-06-02 | Tampering | `sim_data.cpp` serialized AST reader | medium | mitigate | Versioned framing, length/bounds checks, and failure on truncated records. |
| T-06-03 | Information Disclosure | source-location metadata | low | accept | Metadata contains only paths already supplied by the testcase filelist and is used for diagnostics. |
</threat_model>
