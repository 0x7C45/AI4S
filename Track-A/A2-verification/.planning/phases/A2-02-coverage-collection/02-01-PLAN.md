# Plan 02-01: 覆盖率收集 — 行/分支/功能 + 约束随机

## Objective

在 Phase 1 骨架门禁基础上，补全覆盖率采集管道：约束随机配置（constraints.json）、功能 bin 定义（coverage_bins.json）、Verilator coverage.dat LCOV 解析（line/branch）、RTL 死码过滤、功能覆盖采样汇总（functional_coverage.json）、综合覆盖率计算（coverage_result.json，公式 0.4/0.3/0.3）。case1 端到端产出完整 7 JSON。

## Context

- Phase 1 已交付 run.py + rtl_parser + skeleton_gen + sim_runner（骨架门禁通过）
- 烟雾测试 Level 2 已验证 coverage.dat → LCOV 解析管道可用
- case1 Verilator 口径：line 59.95%（含死码）/ branch 72.02%（未过滤 wrapper）
- CONSTRAINTS §10：case1 line 53% 根因是参数化死码（SEGMENT_COUNT/EXPAND 分支恒假）
- 选手自交 coverage_result.json，评测器不锁工具重算

### Locked Decisions (from CONTEXT.md)

- **D-11**: 行覆盖率用 Verilator --coverage-line → LCOV DA 解析
- **D-12**: 分支覆盖率用 --coverage-line 自动产出的 LCOV BRDA
- **D-13**: 功能覆盖率用 cocotb coverage.hit(bin) 真实事务采样（复用 FunctionalCoverage 类）
- **D-14**: 覆盖率按文件过滤排除 wrapper（文件名含 cocotb_top/wrapper）
- **D-15**: 死码分析识别 generate/if/parameter 不可达分支，分母只计可达行
- **D-16**: 综合 C = 0.4×line + 0.3×branch + 0.3×functional（禁止 0.42/0.28/0.30）
- **D-17**: 功能 bin 4 类模板：FSM/数据通路/存储器/AXI 协议
- **D-18**: bin 禁止空 hit / 初始化一次性 hit（CONSTRAINTS §8）
